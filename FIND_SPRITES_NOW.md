# Find Sprites NOW - Working Links

## 🚀 Start Here - These Actually Work

### 1. Kenney.nl (NO ACCOUNT NEEDED)
**Abstract Characters:**
https://kenney.nl/assets/abstract-characters
- Click "Download" → Free, instant download
- Has character sprites ready to use

**Tiny Characters:**
https://kenney.nl/assets/tiny-characters
- Small, simple characters
- Multiple animations included

### 2. OpenGameArt (FREE ACCOUNT)
**Main Site:**
https://opengameart.org

**Direct Search:**
https://opengameart.org/art-search-advanced?keys=character+sprite+sheet&field_art_type_tid%5B%5D=9

**Top Results:**
- Search "LPC character" → Liberated Pixel Cup sprites
- Filter: CC0 license (free, no attribution)
- Download sprite sheets

### 3. Itch.io (FREE ACCOUNT)
**Free Character Assets:**
https://itch.io/game-assets/free/tag-character

**Top Packs:**
- Search "character sprites"
- Sort by: Most downloaded
- Filter: Free, 2D

### 4. Craftpix Freebies
**URL:**
https://craftpix.net/freebies/
- Free character packs
- Requires free account

## 📥 Download Process

1. **Pick a source** (Kenney is easiest)
2. **Download the pack**
3. **Extract ZIP file**
4. **Copy sprites to:**
   - `assets/characters/sprites/` (main sheets)
   - `assets/characters/emotions/` (emotion sprites)
   - `assets/characters/body_language/` (pose sprites)
