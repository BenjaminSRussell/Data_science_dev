
# Maya Chen - The Software Engineer
**Role:** Software Engineer
**Personality:** Friendly, Smart, Geeky

## Character Profile
**Background:** Brilliant engineer. Appreciates intelligence and creativity. Graduated top of her class from MIT.
**Motivation:** Solving difficult problems.
**Secret:** She writes fanfiction about open source frameworks dating each other.
**Dream:** To invent a new programming language that replaces JavaScript.
**Fear:** Burnout.
**Relationship Status:** Looking for someone who understands Big O notation.
**Turning Point:** Contributing to the Linux kernel.
**Philosophy:** "Code is poetry. Logic is art."

*   **Rel > 10 (Background):** "I code in my sleep. Literally. I dreamt of a sorting algorithm last night."
*   **Rel > 25 (Philosophy):** "There's an elegance to clean code. It's like a symphony. Everything in its place."
*   **Rel > 40 (Secret):** "Okay, don't laugh. I wrote a story where React breaks up with Angular. It's... emotional."
