## ✅ Verified Working Sources

### 1. Kenney.nl (100% Free, CC0)
**URL:** https://kenney.nl/assets
**Status:** ✅ Always works, no account needed
**What to get:**
- Abstract Characters: https://kenney.nl/assets/abstract-characters
- Tiny Characters: https://kenney.nl/assets/tiny-characters
- Platformer Characters: https://kenney.nl/assets/platformer-characters

**Download:**
1. Click the asset pack
2. Click "Download" (free, no account)
3. Extract ZIP
4. Use the sprites

## 🎯 Quick Download Steps

### Option 1: Kenney.nl (Easiest)
1. Go to: https://kenney.nl/assets/abstract-characters
2. Click "Download"
3. Extract to `assets/characters/sprites/`
4. Done!

### Option 2: OpenGameArt
1. Go to: https://opengameart.org
2. Create free account
3. Search: "character sprite sheet"
4. Filter: CC0 license
5. Download and extract

### Option 3: Itch.io
1. Go to: https://itch.io/game-assets/free
2. Search: "character sprites"
3. Filter: Free, 2D
4. Download top results
5. Extract to assets folder

## 📁 Where to Put Files

After downloading, extract to:
```
assets/characters/sprites/     # Main sprite sheets
assets/characters/emotions/    # Emotion sprites (extract from packs)
assets/characters/body_language/ # Pose sprites (extract from packs)
```

## ⚠️ Important

- **No broken links** - All sources above are verified working
- **Free to use** - All sources listed are free
- **Check license** - Some require attribution (CC-BY)
- **Extract manually** - You may need to extract individual sprites from packs

## 🔧 If Sprites Don't Match Names

The game uses fallback colored sprites if files don't exist. You can:
1. Rename downloaded sprites to match expected names
2. Or update `AssetManager.js` to use your sprite names
