## What's Included

✅ JSON manifest files (structure preserved)
✅ SVG files (vector graphics, small)
✅ Code and configuration files
✅ Documentation

## Quick Commands

**Check what's ignored:**
```bash
git check-ignore -v path/to/file.png
```

**See ignored files:**
```bash
git status --ignored
```

**Compress assets (optional):**
```bash
# Using pngquant
./scripts/compress-sprites.sh

# Using Node.js
node scripts/compress-assets.js
```
