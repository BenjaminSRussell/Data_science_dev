# Get Sprites - Working Links

## ✅ VERIFIED WORKING - Start Here

### 1. Kenney.nl (EASIEST - No Account)
**Abstract Characters:**
https://kenney.nl/assets/abstract-characters
- Click "Download" → Free, instant
- Has character sprites with animations

**Tiny Characters:**
https://kenney.nl/assets/tiny-characters
- Simple 2D characters
- Multiple poses included

### 2. OpenGameArt (Free Account)
**Search Character Sprites:**
https://opengameart.org/art-search-advanced?keys=character+sprite+sheet

**Filter:**
- Art Type: Sprite/Texture
- License: CC0 (free, no attribution)

### 3. Itch.io (Free Account)
**Free Character Assets:**
https://itch.io/game-assets/free/tag-character

**Sort by:** Most downloaded
**Filter:** Free, 2D

### 4. Craftpix Freebies
https://craftpix.net/freebies/
- Free character packs
- Requires free account

## 📥 Quick Download

1. Go to: https://kenney.nl/assets/abstract-characters
2. Click "Download"
3. Extract ZIP
4. Copy sprites to `assets/characters/sprites/`
5. Done!

## 🎯 What You Need

- Character sprite sheets (64x64 or 128x128 frames)
- Emotion sprites (extract from packs)
- Body language poses (extract from packs)

The game will use colored fallbacks until you add real sprites.
